# Project Domain Glossary

- **the Printing Press**: The CLI generator system in this repo (`cli-printing-press`). Always called "the Printing Press" in skills and user-facing output — never "the machine."
- **printed CLI**: A CLI generated by the Printing Press. Lives at `~/printing-press/library/<api-slug>/`. Distinct from the Printing Press itself.
- **api-slug**: URL-safe identifier derived by the generator from the spec title (e.g. `consigliere`, `hermes`, `poster-engine`). Drives binary name (`<slug>-pp-cli`), module path, and library directory.
- **fast-path**: The `/printing-press` skill — runs the full generation loop in one session (research → generate → build → verify). Contrast with the 9-phase managed pipeline.
- **managed pipeline**: The 9-phase `printing-press pipeline` flow — phased, resumable, inspectable. Used for complex or public-library CLIs; fast-path is preferred for internal APIs.
- **MCP server**: The agent-native surface of a printed CLI, served by `<slug>-pp-cli mcp`. Mirrors all user-facing Cobra commands as MCP tools.
- **tools-manifest.json**: Generated MCP tool catalog for a printed CLI. Lives alongside the binary in the library directory.
- **internal CLI**: A printed CLI targeting a local FastAPI service (no public docs). Spec sourced from `http://localhost:<port>/openapi.json`. No catalog research phase needed.
- **hermes** (CLI slug): The unified CLI covering hermes-adapter (port 9109) — includes backlog, dagu, paperclip, memories, files, chat, and A2A namespaces. Paperclip is not a separate CLI.
- **consigliere** (CLI slug): CLI for the Consigliere OSINT pipeline on port 9104.
- **poster-engine** (CLI slug): CLI for the PosterEngine FastAPI on port 9120.
